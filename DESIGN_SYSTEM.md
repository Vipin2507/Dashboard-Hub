# Buildesk visual language

Source of truth for UI. Internal SaaS admin / CRM — dense, calm, data-first.

- Canvas: cool gray `#f4f7fb` (dark navy-black `#060e18`)
- Cards: white / `#0c1826` with `--shadow-soft`
- Brand: `#009bff` only (`#2eb0ff` in dark)
- Rail: dark navy `#0b1f33`, 52px collapsed / 208px expanded
- Type: Inter, compact (`text-xs` / `text-sm`), tabular KPIs
- Motion: `EASE = [0.22, 1, 0.36, 1]`, hover `y: -1`, theme 700ms crossfade
- Utility: `card-soft`

Do not revert to zinc + violet shadcn defaults or large marketing typography on inner pages.
